# Notes App 📝

A full-stack Notes application (currently backend in progress) built with **Node.js, Express, MongoDB, and JWT authentication**.  
This project is designed to help users securely create and manage personal notes.

---

## 🚀 Features (Implemented so far)

- Basic Express server setup
- Environment variable management with dotenv
- MongoDB connection using Mongoose

---
